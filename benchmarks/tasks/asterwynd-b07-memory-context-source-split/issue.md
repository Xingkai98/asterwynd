# 长读取 + 小改动：记忆注入逻辑归属收编

上下文注入管线把各类信息源渲染进系统提示词，其中「项目记忆摘要」块由一个注入源负责：它从持久记忆存储读摘要，渲染成固定的「## Project Memory」markdown 块。当前这段**渲染逻辑内联在 context 层的注入源里**——而「记忆如何被摘要、如何呈现给上下文」本质是记忆层（`agent/memory/` 目录下已有去重/持久化/衰减/检索/摘要等 6 个实现模块）的职责。注入源应只做「取存储、委托渲染」，把 block 拼接逻辑收编到记忆层。

**改动要求**：通读上下文注入管线与记忆层，把记忆摘要块的渲染逻辑下沉到记忆层的明确归属（新增一个 memory 层模块），注入源改为委托调用；对外行为必须完全不变（输出文本逐字一致），只动归属不动物理行为。

## Task

- 记忆层新增一个「上下文渲染」归属模块，导出一个纯函数：入参为持久记忆存储，产出现有的「## Project Memory」摘要块文本；无摘要时返回空串
- context 层注入源的 render 改为调用该函数（懒加载导入，避免注入管线在启动时拉入记忆层实现细节）
- 不改渲染文本、不改注入源对外接口、不加新依赖

判定标准（双断言）：
1. **新模块路径可用**：`render_memory_index` 可从记忆层新模块导入，且对已有记忆直接产出含该记忆的摘要块
2. **行为保持**：注入源经委托后的 render 输出与新模块输出逐字一致

## Requirements

- 记忆层新模块导出 `render_memory_index(memory)` 纯函数（空摘要 → 空串）
- 注入源 render 委托给新模块，输出与下沉前逐字一致
- 既有上下文构建 / 注入源 / 记忆层测试不得回归
